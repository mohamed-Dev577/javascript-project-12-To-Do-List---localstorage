# 📝 To-Do List with LocalStorage

تطبيق قائمة مهام باستخدام JavaScript مع حفظ البيانات في LocalStorage حتى بعد إعادة تحميل الصفحة.

---

## 🚀 فكرة المشروع

يسمح التطبيق للمستخدم بـ:
- إضافة مهام جديدة
- عرض المهام تلقائيًا بعد Refresh
- حفظ المهام داخل المتصفح

---

## 🛠️ التقنيات المستخدمة

- HTML5
- CSS3
- JavaScript (DOM)
- LocalStorage API

---

## ✨ المميزات

- إضافة المهام بسهولة
- حفظ البيانات داخل المتصفح
- استرجاع المهام بعد إعادة فتح الصفحة
- تحديد المهمة كمكتملة
- حذف المهام

---

## 🧠 المفاهيم المستخدمة

- DOM Manipulation
- Arrays
- Functions
- localStorage
- JSON.stringify
- JSON.parse

## ▶️ طريقة التشغيل

1. افتح ملف `index.html`
2. اكتب مهمة جديدة
3. اضغط على زر "إضافة"
4. جرّب عمل Refresh للصفحة وستجد المهام محفوظة
